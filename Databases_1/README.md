# Databases 1 - Laboratory Exercises

This repository contains all laboratory projects (Lab 1 to Lab 5) completed as part of the Databases 1 course at Hochschule Esslingen.

## Project Overview
The lab exercises focused on fundamental database concepts using IBM DB2. Topics included database setup, instance and connection management, transaction control, locking, concurrency, isolation levels, table space and storage management, as well as user privileges and security.

## Tools and Technologies
- IBM DB2
- DB2 Command Line Processor (CLP)
- SQL
- Windows environment

## Labs Summary
- **Lab 1:** Introduction to DB2 environment, CLP, and registry variables
- **Lab 2:** Remote access, instance configuration, and database catalogs
- **Lab 3:** Transaction management and concurrency control
- **Lab 4:** Storage structures and table space calculation
- **Lab 5:** User privileges, roles, and security in DB2
