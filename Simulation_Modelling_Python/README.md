# Simulation Projects (04 Series)

This repository contains a set of simulation projects developed using Python and Jupyter Notebooks. The focus is on modeling and solving problems in control systems, robotics, optimization, and physics.

## Included Notebooks
- **quarter_car_04.ipynb** – Simulation of a quarter-car suspension system
- **robot_04.ipynb** – Basic robot kinematics and control
- **tsp_04.ipynb** – Traveling Salesman Problem solved with heuristic algorithms
- **water_waves_04.ipynb** – Simulation of wave propagation in water using numerical methods

## Technologies Used
- Python
- NumPy, SciPy, Matplotlib
- Jupyter Notebook
