# Radio Clock with Temperature Sensor (HCS12 Project)

This project was developed as part of the Computer Architecture course.  
The goal was to program a radio-controlled clock with temperature sensing capabilities using the Freescale HCS12 16-bit microcontroller.

## Project Overview
The clock receives time data via radio signals and displays it, along with real-time temperature readings. Development was done using a mix of Assembly and C, targeting low-level microcontroller features.

## Technologies and Tools
- **Microcontroller:** Freescale HCS12 (16-bit)
- **Languages:** Assembly and C
- **Development Tools:** CodeWarrior, HCS12 Simulator/Hardware

## Key Features
- Time synchronization via radio signal
- Temperature measurement using analog input
- Custom subroutines for time parsing, display control, and temperature calculation
- Use of interrupts for efficient signal handling and sensor reading
