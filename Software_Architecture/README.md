# Jodel Clone Web Application

This project was developed as part of the Software Architecture course.  
It is a simplified clone of the Jodel app, allowing users to post messages, like posts, and comment on them.

## Project Overview
The main objective was to design a modular, scalable web application with user authentication and basic social interaction features like posting, liking, and commenting.

## Technologies Used
- **Frontend:** React
- **Backend:** Spring Boot
- **Authentication:** Keycloak (OAuth2)
- **Database:** PostgreSQL
- **Containerization:** Docker

## Features
- User authentication with Keycloak
- Create, like, and comment on posts
- Modular architecture with separate services
- Dockerized for easy deployment
