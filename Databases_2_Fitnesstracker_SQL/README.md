# Fitness Tracker Web Application

This project was developed as part of the Databases 2 course at Hochschule Esslingen.  
It is a fitness tracking web application that allows users to manage their workouts and exercises, built to explore database integration and full-stack development.

## Project Overview
The goal was to implement a responsive and functional web application that allows users to create, edit, and manage workouts and exercises. Users can input sets, weights, and repetitions, and view statistics such as average weight and reps per exercise.

## Technologies Used
- **Frontend:** Vue.js
- **Backend:** Spring Boot (Java)
- **Database:** Microsoft SQL Server

## Key Features
- CRUD operations for workouts and exercises
- Dynamic calculation of average values using stored procedures and functions
- Intuitive UI with a focus on usability and training analysis

## Challenges
The main challenges included:
- Designing a relational data model for workouts and exercises
- Implementing complex SQL queries for aggregation and statistics
- Seamless integration between frontend and backend
